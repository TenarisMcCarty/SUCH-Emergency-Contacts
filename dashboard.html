  2. Token name: Emergency cards dashboard. Expiration: the longest offered.

          How it works

          Each family or school has a card with an NFC tag and QR code. Tapping or scanning it opens a page with a Text all button and Call buttons. The person on shift right now is at the top. Changes you publish here reach every card within about a minute.

          Common jobs

          • Shift rotation changed: Shifts → tick who works each shift → Publish.
          • New person / someone left: People → Add person or Remove → check Shifts → Publish.
          • New card: Cards → Add card → Publish → Print & QR → download the files, write the link to the tag. Test it, then lock the tag.
          • Lost card: Cards → Remove next to it → Publish. Only that card stops working.
          • Name typo on a card: Cards → Rename → Publish. The tag doesn't need rewriting, but print a new card face.
          • Give someone access: send them this page's link and tell them the password (in person or by phone).
          • Spanish: families can switch the card page to Spanish (phones set to Spanish open it in Spanish). Fill in the Spanish boxes in People and Shifts so roles and shift names read naturally; anything left blank shows in English.

          If something's wrong

          • "Not published" won't go away: press Publish and read the message under it.
          • Publishing isn't working: ask the site owner.
          • Someone else published first: Lock, sign in again, redo your change.
          • Forgot the password: ask the site owner to reset it.

          Security

          All data is encrypted before it leaves this page. Each card can unlock only the contacts and its own driver's name. The password never leaves this device.
