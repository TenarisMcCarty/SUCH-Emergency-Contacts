Connect to GitHub

Publishing needs a GitHub token that can change only this one repository. Make it while signed in to GitHub as TenarisMcCarty:

  1. Open GitHub → New fine-grained token.
  2. Token name: Emergency cards dashboard. Expiration: the longest offered.
  3. Repository access: Only select repositories → SUCH-Emergency-Contacts.
  4. Permissions: Repository permissions → Contents → Read and write. Leave everything else as is.
  5. Generate token, copy it (starts with github_pat_) and paste it below.

          How it works

          Each family or school has a card with an NFC tag and QR code. Tapping or scanning it opens a page with a Text all button and Call buttons. The person on shift right now is at the top. Changes you publish here reach every card within about a minute.

          Common jobs

          • Shift rotation changed: Shifts → tick who works each shift → Publish.
          • New person / someone left: People → Add person or Remove → check Shifts → Publish.
          • New card: Cards → Add card → Publish → write the link to the tag (NFC Tools) and use the QR for the print. Test it, then lock the tag.
          • Lost card: Cards → Remove next to it → Publish. Only that card stops working.
          • Name typo on a card: Cards → Rename → Publish. No need to rewrite the card.
          • Give someone access: send them this page's link and tell them the password (in person or by phone).
          • Take away access: Settings → tick "Someone who should lose access…" → Change password → Publish.

          If something's wrong

          • "Not published" won't go away: press Publish; read the message under it.
          • GitHub token problem: Settings → Replace GitHub token (instructions are on that screen).
          • Someone else published first: Lock, sign in again, redo your change.

          Security

          All data is encrypted before it leaves this page. Each card can unlock only the contacts and its own driver name. The password never leaves this device.
